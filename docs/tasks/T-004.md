Entradas canónicas: domain.schema.json y OpenAPI; `openapi-typescript` major 7, patch exacto
verificado y fijado en package.json/lock en esta tarea. Generador en tools/generate_contracts.py
orquesta exportación determinista y validación, sin implementar endpoints. Salida de tipos
web/src/api/generated/schema.d.ts; wrapper de fetch en web/src/api/client.ts con cookies,
CSRF e idempotencia según doc11. No SDK ni dominio Python en el frontend.

## Pruebas y aceptación AC-004

Dos generaciones idénticas producen mismo hash; modo --check no escribe y falla si hay diff.
Cambiar campo requerido/tipo/enum detecta incompatibilidad; no aceptarlo regenerando a ciegas.
Fixtures tsc: Money.atoms=number falla; string válida compila; nullable requiere guard; errores
Problem se manejan con status/code. El wrapper nunca convierte atoms a Number ni reintenta POST
con una clave nueva. Tests HTTP stub verifican 401,403,409,429 y cancelación por AbortSignal.
JSONSchema sigue siendo autoridad runtime: TypeScript no prueba allOf ni reglas entre campos.
`make check` más test del generador y tsc de fixtures. No base de datos necesaria.
