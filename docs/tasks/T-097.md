## Reglas, invariantes y errores

Crash tras envío no crea firma nueva ni libera reserva

Conservar INV-01–INV-18 aplicables. Identidad y unidad nunca se infieren de un ticker. Un resultado desconocido no se convierte en 0/false/éxito. Repetición del mismo input no duplica efectos. Fallo de persistencia no confirma comando mutante. Propagar error saneado y código estable; retry sólo dentro de política y deadline.
