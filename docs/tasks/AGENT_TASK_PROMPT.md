# Encargo para agente implementador

Trabajá exclusivamente en la tarea que te asigne el coordinador. Para empezar este proyecto, la tarea es **T-001**.

Leé su ficha, índice, invariantes, contratos, ADR y las instrucciones actuales del repositorio. Comprobá HEAD, rama y cambios ajenos antes de editar. Verificá dependencias y bloqueos; no inventes APIs o requisitos faltantes.

Implementá sólo el alcance indicado. Conservá dinero real bloqueado, permisos mínimos y lógica de riesgo determinista. No añadas dependencias ni cambies arquitectura sin decisión registrada. Usá pruebas que demuestren el objetivo y el caso adversarial, ejecutalas y guardá evidencia reproducible.

Si hay contradicción, registrá SPEC-CONFLICT y bloqueá sólo el efecto afectado. Si una API, licencia o dataset no está disponible, usá fixtures para el trabajo local y declaralo; no presentes eso como prueba de integración.

Entregá ID, estado, commit base/final, diff, archivos modificados, comandos con exit codes, resultados, limitaciones y bloqueos. No declares DONE si falló un criterio. No hagas push/merge ni pases a la siguiente tarea automáticamente sin autorización de coordinación.
