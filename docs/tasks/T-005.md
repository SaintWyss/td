## Reglas y aceptación AC-005

Domain (incluidas estrategias) sólo stdlib pura y otros módulos domain. Ports sólo stdlib
tipado y domain. Application puede domain/ports y application; no adapters/entrypoints/frameworks.
Adapters implementan ports y pueden SDK/ORM; entrypoints llaman application. Sólo composition
root enlaza implementaciones concretas. Rechazar imports relativos que crucen esas fronteras,
imports dentro de funciones y TYPE_CHECKING igual que top-level. Import dinámico en domain,
ports o application se prohíbe (importlib.import_module, __import__), no se intenta adivinarlo.
Permitir datetime como tipo, prohibir llamadas datetime.now/time.time en dominio según inspección
AST; Clock se inyecta. Fixtures temporales prueban import válido, FastAPI/SQLAlchemy/httpx
prohibidos, relativo escapado, import dentro de función y alias. Nunca ejecutar el fixture.
`uv run --frozen pytest tests/unit/test_import_boundaries.py -q` y `make check`.
