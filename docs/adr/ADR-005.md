# ADR-005 — LLM fuera del control financiero

Estado: ACCEPTED para diseño, pendiente de implementación. Fecha:2026-11-03. Responsable de cambios: propietario técnico.

## Contexto

Texto externo puede ser falso o contener instrucciones.

## Decisión

LLM propone datos/hipótesis; Risk/Executor deterministas con permisos distintos.

## Alternativa descartada

Agente con wallet y shell cruza la frontera de confianza.

## Consecuencias y verificación

Gateway con schemas/budget; abstenerse ante refusal/injection. La tarea correspondiente debe aportar prueba positiva y negativa, fixture reproducible y revisión de compatibilidad antes de integrar. Si el supuesto cambia, crear ADR que superseda éste; no modificarlo silenciosamente.
