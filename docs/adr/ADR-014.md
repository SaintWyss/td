# ADR-014 — Ejecución propia restringida

Estado: ACCEPTED para diseño, pendiente de implementación. Fecha:2026-11-03. Responsable de cambios: propietario técnico.

## Contexto

Un router ofrece rutas con capacidades distintas.

## Decisión

Quotes Jupiter V2; futuro build con instrucciones inspeccionadas y RPC propio.

## Alternativa descartada

Managed execute de cualquier ruta añade formatos/actores no certificados.

## Consecuencias y verificación

Más trabajo de decoding; bloquear rutas que no se entienden. La tarea correspondiente debe aportar prueba positiva y negativa, fixture reproducible y revisión de compatibilidad antes de integrar. Si el supuesto cambia, crear ADR que superseda éste; no modificarlo silenciosamente.
