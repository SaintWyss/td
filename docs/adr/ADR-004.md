# ADR-004 — Persistencia y entrega

Estado: ACCEPTED para diseño, pendiente de implementación. Fecha:2026-11-03. Responsable de cambios: propietario técnico.

## Contexto

Se necesita reconstrucción de efectos tras crash.

## Decisión

Postgres outbox/receipts y Parquet inmutable por manifest; entrega al menos una vez.

## Alternativa descartada

Redis como saldo o promesa exactly-once de red no resuelven ambigüedad externa.

## Consecuencias y verificación

Índices de unicidad, leases y fencing; ninguna pérdida por ACK temprano. La tarea correspondiente debe aportar prueba positiva y negativa, fixture reproducible y revisión de compatibilidad antes de integrar. Si el supuesto cambia, crear ADR que superseda éste; no modificarlo silenciosamente.
