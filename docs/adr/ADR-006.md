# ADR-006 — Baseline CPU antes de modelos grandes

Estado: ACCEPTED para diseño, pendiente de implementación. Fecha:2026-11-03. Responsable de cambios: propietario técnico.

## Contexto

No hay dataset/alpha demostrados y GPU tiene recursos limitados.

## Decisión

Reglas/logística/LightGBM primero; XGB/fundacionales challengers.

## Alternativa descartada

Más parámetros no prueba ventaja y complica licencias/contaminación.

## Consecuencias y verificación

Mismo presupuesto experimental y artefactos congelados. La tarea correspondiente debe aportar prueba positiva y negativa, fixture reproducible y revisión de compatibilidad antes de integrar. Si el supuesto cambia, crear ADR que superseda éste; no modificarlo silenciosamente.
