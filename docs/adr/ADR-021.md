# ADR-021 — Contexto explícito, UoW e historial con corte estable

Estado ACCEPTED_DESIGN, 2026-11-06. Resuelve GD-12 en draft1.2.

Decisión: contexto autenticado/deadline/cancelación fuera del payload de negocio; errores tipados
con effect_state; Clock e ID generator inyectados; UnitOfWork serializable con status recuperable;
JobQueue con lease/fencing; AuditSink atómico; EvidenceReader con hash/permisos. Historiales
separados por tipo con filtro bitemporal, snapshot watermark, cursor ligado a filtros y cobertura.

Razón: una interfaz de sólo nombres no permite distinguir ausencia, timeout, commit incierto y
datos incompletos; paginar contra NOW variable permite pérdida/duplicación o información futura.

Consecuencias: 50 métodos declarados, requests/resultados/errores en schema canónico; implementadores
siguen contratos sin inventar retry ni transacciones. No se introduce un repositorio genérico de SQL
ni un canal de efectos arbitrarios. Evidencia documental no es verificación runtime.

Referencias: ../contracts/auxiliary-ports.md y ../contracts/ports.json. Mantener gates existentes.
