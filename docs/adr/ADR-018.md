# ADR-018 — Rutas por responsabilidad y delegabilidad explícita

Estado: ACCEPTED, 2026-11-04.

Se conservan T-001–T-144 y se reemplazan destinos de producción t_NNN por nombres de
responsabilidad; pruebas pueden conservar IDs para trazabilidad. Tabla completa:
[path-migrations.json](../../audit/g-design/path-migrations.json). Son destinos previstos,
no implementación. T-004 se mueve a generación de contratos; T-005 a herramienta AST.

T-006/T-008 requieren T-009 porque sus sesiones/auditoría se persisten en PostgreSQL.
T-005 requiere sólo bootstrap, no el Settings de una plantilla. T-033 implementará harness
con puertos/fixtures; T-054/T-056 conectarán comportamiento real. Se evita un ciclo con
Strategy/Risk sin afirmar que un stub ya valida finanzas. T-049 consume señales tipadas
en fixtures y se integra con S02 posteriormente.

Una sección presente no acredita delegabilidad. El registro individual distingue diseño,
dependencias implementadas, permisos externos y ensayo empírico. G-DESIGN global continúa
bloqueando implementación aunque una ficha concreta esté DESIGN_READY. No se dividieron
IDs ni se añadió alcance funcional; el trabajo documental pendiente está en los hallazgos.
