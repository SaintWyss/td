# ADR-001 — Monolito modular

Estado: ACCEPTED para diseño, pendiente de implementación. Fecha:2026-11-03. Responsable de cambios: propietario técnico.

## Contexto

La RAM es limitada y el producto necesita consistencia financiera.

## Decisión

Un repo y DB, módulos hexagonales y procesos acotados; signer futuro aislado.

## Alternativa descartada

Microservicios/Kafka agregan despliegue y fallos distribuidos sin carga que lo justifique.

## Consecuencias y verificación

Import rules y roles de DB son obligatorios; separar procesos no elimina acoplamiento si comparten privilegios. La tarea correspondiente debe aportar prueba positiva y negativa, fixture reproducible y revisión de compatibilidad antes de integrar. Si el supuesto cambia, crear ADR que superseda éste; no modificarlo silenciosamente.
