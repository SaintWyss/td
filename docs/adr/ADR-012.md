# ADR-012 — Promoción humana

Estado: ACCEPTED para diseño, pendiente de implementación. Fecha:2026-11-03. Responsable de cambios: propietario técnico.

## Contexto

Un modelo que se evalúa solo puede redefinir éxito.

## Decisión

Challenger no cambia champion; promoción CAS tras gates y revisión.

## Alternativa descartada

Auto-promover por mejor backtest confunde entrenamiento con evidencia.

## Consecuencias y verificación

Se puede automatizar recopilación, no la aprobación. La tarea correspondiente debe aportar prueba positiva y negativa, fixture reproducible y revisión de compatibilidad antes de integrar. Si el supuesto cambia, crear ADR que superseda éste; no modificarlo silenciosamente.
