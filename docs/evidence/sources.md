# Fuentes oficiales consultadas

**S01. [Helius pricing](https://www.helius.dev/pricing)** — Planes, créditos y cuotas; no extrapolar beta vencida.

**S02. [Helius RPC](https://www.helius.dev/docs/rpc/guides/overview)** — RPC y herramientas de lectura; benchmark propio pendiente.

**S03. [Solana sendTransaction](https://solana.com/docs/rpc/http/sendtransaction)** — Aceptación RPC no implica confirmación.

**S04. [Solana logsSubscribe](https://solana.com/docs/rpc/websocket/logssubscribe)** — Filtro mentions de una dirección.

**S05. [Solana getSignaturesForAddress](https://solana.com/docs/rpc/http/getsignaturesforaddress)** — Paginación por before/until; blockTime nullable.

**S06. [Solana getTransaction](https://solana.com/docs/rpc/http/gettransaction)** — Consulta de transacción con versión/commitment; null posible.

**S07. [DEX Screener API](https://docs.dexscreener.com/api/reference)** — Rutas de pairs/tokens y cuotas publicadas.

**S08. [Birdeye precios](https://docs.birdeye.so/docs/pricing)** — Planes/CU y límites; derechos de uso se revisan aparte.

**S09. [Birdeye tipos de datos](https://birdeye.so/data-api/types-of-data)** — Catálogo de OHLCV/trades/holders/security.

**S10. [Jupiter Order & Execute](https://developers.jup.ag/docs/swap/order-and-execute)** — Swap V2 con orden, firma y ejecución; existe ruta build según índice oficial.

**S11. [Jupiter rate limits](https://developers.jup.ag/docs/portal/rate-limits)** — Cuotas por organización y buckets.

**S12. [Raydium program addresses](https://docs.raydium.io/reference/program-addresses)** — Identidad de CPMM; cotejo on-chain requerido.

**S13. [Kraken L2](https://docs-legacy.kraken.com/api/docs/websocket-v2/book/)** — Book agregado y checksum.

**S14. [Telegram Content Licensing](https://telegram.org/tos/content-licensing)** — Restricciones IA y excepciones contextuales.

**S15. [Reddit Data API Terms](https://redditinc.com/policies/data-api-terms)** — Se consultó la página; licencia suficiente para TD no establecida.

**S16. [X Developer Policy](https://docs.x.com/developer-terms/policy)** — Política contractual; licencia IA suficiente no establecida.

**S17. [OpenAI API pricing](https://developers.openai.com/api/docs/pricing)** — Precios estándar de modelos elegidos, no suscripción ChatGPT.

**S18. [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)** — Subconjunto JSON Schema, validación local necesaria.

**S19. [Anthropic pricing](https://claude.com/pricing)** — Tarifas de API y diferencia contexto corto/largo.

**S20. [Claude Haiku 5.5](https://platform.claude.com/docs/en/models/haiku-5-5/overview)** — ID de API y capacidades documentadas.

**S21. [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing.md)** — ID y tarifa Flash-Lite; tratamiento free/paid distinto.

**S22. [LightGBM](https://github.com/lightgbm-org/LightGBM)** — Biblioteca de gradient boosting, repositorio oficial.

**S23. [XGBoost](https://github.com/dmlc/xgboost)** — Gradient boosting, Apache-2.0 del código.

**S24. [Kronos](https://github.com/shiyu-coder/Kronos)** — Modelos mini/small y ventanas; no evidencia de PnL de TD.

**S25. [Chronos](https://github.com/amazon-science/chronos-forecasting)** — Familias Bolt y checkpoints compactos.

**S26. [TimesFM](https://github.com/google-research/timesfm)** — Código Apache; aviso de pesos3.0 no comerciales/no producción.

**S27. [FinBERT](https://github.com/ProsusAI/finBERT)** — Aviso 2026-10-12 distingue código/pesos/dataset.

**S28. [FinGPT](https://github.com/AI4Finance-Foundation/FinGPT)** — Framework NLP financiero; licencias por artefacto necesarias.

**S29. [DeepLOB](https://arxiv.org/abs/1808.03668)** — Predicción LOB de acciones; no validación directa en AMM.

**S30. [FinRL](https://github.com/AI4Finance-Foundation/FinRL)** — Framework RL; no justifica promoción sin simulador validado.

**S31. [Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)** — Corrección de selección múltiple/no normalidad; supuestos siguen importando.

**S32. [CNV RG1058/2025](https://www.argentina.gob.ar/normativa/nacional/resoluci%C3%B3n-1058-2025-410635/texto)** — Texto oficial con delimitación de actividad por cuenta propia.

**S33. [CNV RG1172/2026](https://www.argentina.gob.ar/normativa/nacional/norma-431259/texto)** — Modifica régimen PSAV; requiere revisión aplicada al producto.

**S34. [FreqAI](https://www.freqtrade.io/en/stable/freqai/)** — Entrenamiento adaptativo y sandbox de modelos.

**S35. [Hummingbot Condor](https://hummingbot.org/condor/)** — Separación de razonamiento y ejecución.

**S36. [LEAN](https://github.com/QuantConnect/Lean)** — Motor algorítmico modular; no se adopta como núcleo inicial.

**S37. [Lo, Mamaysky y Wang](https://www.nber.org/papers/w7613)** — Información incremental de patrones en muestra histórica, no garantía neta actual.

**S38. [PostgreSQL version policy](https://www.postgresql.org/support/versioning/)** — Política de soporte/migraciones.

**S39. [Pydantic](https://pydantic.dev/docs/validation/latest/get-started/)** — Validación tipada y JSON Schema.

**S40. [FastAPI](https://fastapi.tiangolo.com/)** — Framework API y validación/OpenAPI.
